# Sound Grid Composer

A simple sound pad application for Android that allows you to create music by tapping on a grid of colorful buttons. Each button plays a different sound effect, and sounds can be looped by long-pressing.

## Features

- 4x4 grid of colorful, rounded square buttons
- Each button plays a different sound (drums, piano, synth, effects)
- Short tap plays sound once
- Long press causes sound to loop with regular intervals
- Visual feedback when buttons are pressed
- Notification sent when sounds are played

## Setting Up Sound Files

The app requires 16 different sound files in the `app/src/main/res/raw` directory. Download free, royalty-free sound samples from the following websites:

- [Freesound.org](https://freesound.org/)
- [Mixkit Free Sound Effects](https://mixkit.co/free-sound-effects/)
- [SoundBible](https://soundbible.com/)
- [ZapSplat](https://www.zapsplat.com/)

### Required Sound Files

Add the following .mp3 or .wav files to your `app/src/main/res/raw` directory:

1. `drum1.mp3` - Bass drum sound
2. `drum2.mp3` - Snare drum sound
3. `drum3.mp3` - Hi-hat sound
4. `drum4.mp3` - Cymbal sound
5. `piano1.mp3` - Piano C chord
6. `piano2.mp3` - Piano G chord
7. `piano3.mp3` - Piano F chord
8. `piano4.mp3` - Piano Am chord
9. `synth1.mp3` - Synthesizer pad sound
10. `synth2.mp3` - Synthesizer arpeggio
11. `synth3.mp3` - Synthesizer bass
12. `synth4.mp3` - Synthesizer lead
13. `fx1.mp3` - Sound effect 1
14. `fx2.mp3` - Sound effect 2
15. `fx3.mp3` - Sound effect 3
16. `fx4.mp3` - Sound effect 4

Make sure the sounds are:
- Short (ideally less than 2 seconds)
- Different from each other
- Clear and high quality
- Properly trimmed (no silence at beginning or end)

## Usage Tips

- Tap different buttons in sequence to create rhythms
- Use long-press to create looping background patterns
- Combine different sound types for interesting compositions
- Experiment with different rhythmic patterns

## Notes

When selecting sound samples, try to choose sounds that complement each other tonally and rhythmically. For best results, select sounds that are within the same musical key or compatible keys.
